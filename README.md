## Goldbach's Conjecture: Two Mathematicians, Two Major Breakthroughs

A 1:45 narrated motion-graphics explainer on Chen Jingrun (Chen's Theorem, 1973) and Harald Helfgott (Weak Goldbach Conjecture, 2013).

- `goldbach-conjecture/video/goldbach_16x9_VO_chat.mp4` — 1080p, with voice-over
- `goldbach-conjecture/video/goldbach_16x9_noVO_chat.mp4` — 1080p, music and effects only
- `goldbach-conjecture/video/*_hq.mp4` — high-bitrate versions of both (about 86 MB each)
- `goldbach-conjecture/source/` — narration script, timeline, canvas animation (`film/index.html?play` plays it in a browser) and the score script
